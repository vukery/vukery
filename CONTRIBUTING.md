# Contributing

**vukery is an AI-driven project.** It's designed, written, tested and
documented by its maintainer working with an AI assistant, following a set
of opinions and decisions that keep it small and consistent.

## Pull requests

You're welcome to open one, but **it will probably not be merged.** That's
not about the quality of your work: changes come in through the way the
project is built, and outside code is hard to fold into that.

What does help:

- **Issues.** Bug reports (with steps to reproduce), questions, and ideas,
  especially from people migrating an MPF game. They're read, and good ideas
  get built.
- **Example games and configs.** Seeing how vukery is used, or where it falls
  short, shapes what gets built next.

## Want something different? vuk yourself

If you want vukery to work differently, **fork it**. vukery is MIT
licensed, so you can take it in any direction you like: add hardware
platforms, change the opinions, build a whole new framework on top of it.

If you do, please:

- keep the MIT license and the copyright notices, including MPF's notices
  on the code that came from the
  [Mission Pinball Framework](https://github.com/missionpinball/mpf)
  (listed in
  [vukery/_mpf/NOTICE](https://github.com/vukery/vukery/blob/main/vukery/_mpf/NOTICE));
- give your fork its own name, so nobody mixes it up with vukery.
